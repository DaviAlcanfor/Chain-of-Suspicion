# 0008 — Python 3.14 em vez de 3.15

- Status: aceita (verificado em 02/11/2026)

## Contexto

Queríamos Python 3.15 por causa dos imports preguiçosos (PEP 810).

## Decisão

Python 3.14 (`requires-python >=3.14`). O 3.15 está em beta (`3.15.0b4`) e a instalação do `langgraph` falha no Windows: `zstandard` (via `langsmith`) não tem wheel `cp315` e tenta compilar com Visual C++. Em 3.14 `langgraph`, `langchain-openai`, `langchain-anthropic`, `fastapi`, `dishka`, `wireup` e `tenacity` instalam e importam.

## Consequências

- Sem `lazy import` por enquanto. Reavaliar quando as dependências tiverem wheel para 3.15.
- O pacote foi renomeado de `jogo` para `chain_of_suspicion`.
